# Yalu Brasil — versão alinhada à referência visual

Site estático responsivo com identidade visual baseada nas referências fornecidas.

## Arquivos
- `index.html` — página inicial e apresentação das experiências.
- `campanha-boas-vindas-beauty.html` — página da campanha Beauty.
- `campanha-boas-vindas-corporal.html` — página de estética corporal.
- `spa-dos-pes.html` — página dedicada ao ritual Spa dos Pés.
- `css/style.css` — cores, tipografia, componentes e responsividade.
- `js/main.js` — menu mobile e ano automático no rodapé.
- `assets/img/` — logotipo, fotografias e arte de Spa dos Pés fornecida.

## Como visualizar
Extraia a pasta e abra `index.html` no navegador. Mantenha a estrutura das pastas para que CSS, JavaScript e imagens sejam carregados corretamente.

## Antes de publicar
Confirme com a equipe os preços, condições, serviços incluídos, validade das campanhas e número de WhatsApp. O site evita publicar valores ou regras comerciais que não foram confirmados.

## Referências visuais adicionais
A versão foi aquecida com tons de caramelo, terracota e areia, preservando o verde-eucalipto como cor de marca. A arte de Spa dos Pés enviada foi incluída como imagem e suas seis etapas foram transcritas para a página dedicada.

## Carrossel de rituais
A seção “Seu momento, seu ritual” usa cards com imagens em blur. No desktop, o hover revela a imagem; em telas touch, tocar no card o ativa. As imagens do carrossel usam fotografias e artes já incluídas em `assets/img/`; substitua os caminhos em `index.html` quando tiver fotos próprias de cada protocolo.


## Versão de continuidade

Esta versão preserva a estrutura, as páginas, as imagens reais e os componentes já desenvolvidos. A única alteração visual aplicada nesta entrega foi aumentar discretamente a logo no mobile para 145px; a altura do cabeçalho e o posicionamento foram mantidos. O tamanho da logo no desktop não foi alterado.

Para testar, abra esta pasta no VS Code e execute `index.html` com o Live Server.
